# Portfolio project rules

Static-exported Next.js 16 personal site for Brendah Nyanchama.

## Framework & docs

- Next.js 16.4.0 + React 19.3.0 + Tailwind v4, package manager **bun** (bun@1.3.14).
- This Next.js has breaking changes vs. older training data. The bundled docs at
  `node_modules/next/dist/docs/` are the source of truth — read them for app
  router, metadata/generateMetadata, static exports, generateStaticParams, basePath.
- **Do NOT modify** the AGENTS.md block between `BEGIN:nextjs-agent-rules` and
  `END:nextjs-agent-rules`. It is regenerated by `next dev`.
- Path alias `@/` maps to the repo root.

## Static-export rules

- `next.config.ts`: `output: "export"`, `trailingSlash: true`,
  `images: { unoptimized: true }`, `basePath`/`assetPrefix` from
  `NEXT_PUBLIC_BASE_PATH`. Do not change it.
- Dynamic route params are a **Promise** in Next 16 — `await params`.
- `app/projects/[slug]/page.tsx` uses `generateStaticParams` + `dynamicParams = false`.
- `public/.nojekyll` must exist so GitHub Pages serves `_next/`.
- Client components must guard `window`/`matchMedia`/`IntersectionObserver` inside
  `useEffect` — the export prerenders at build time.

## Content & data

- `data/site.ts` is the **single source of truth** for all personal info. Render its
  data exactly; never invent content or add placeholders.
- TS gotcha: empty arrays are `[] as T[]`, NOT `[] satisfies T[]` (which infers
  `never[]`). `stats` is intentionally empty — the stats row is hidden.
- The MGCI experience entry has `start: ""`/`end: ""` — render it with NO date range.
  Do not invent dates. No "Second Class"/honours text anywhere.
- Markdown projects live in `content/projects/*.md`; the filename is the slug.
  `lib/projects.ts` validates required `title`/`description`/`date` at build time and
  THROWS naming the file and field when a required field is missing — the build is
  meant to fail on bad frontmatter.

## Architecture

- Server Components by default. The ONLY client components (small, isolated, in
  `components/`): `SectionNav` (scroll-spy), `Reveal` (reveal-on-scroll),
  `CountUp` (unused since stats is empty, but kept), `SkillBar` (animated bars).
- Every animation has a `prefers-reduced-motion` fallback to its final/static state;
  the global CSS reset neutralizes motion while scroll-spy still works.

## Design system (FINAL — `app/globals.css` @theme; do not change token values)

Dark navy base + single teal accent. Ten tokens:

- `--color-bg #0b1221`, `--color-surface #111a2e`, `--color-surface-2 #16213a`
- `--color-foreground #e6edf6`, `--color-muted #94a3b8`, `--color-faint #64748b`
- `--color-accent #5eead4`, `--color-accent-strong #2dd4bf`,
  `--color-accent-contrast #04231f`, `--color-border #233049`

System fonts only (`--font-sans` system stack, `--font-mono` ui-monospace stack);
**do not use `next/font/google`**. The site is dark by default.

Layout: two-column shell — content scrolls on the **LEFT**, intro sidebar is
`lg:sticky` on the **RIGHT** (`lg:grid-cols-[minmax(0,1fr)_22rem]`); single column
with a mobile header below `lg`. Monospace numbered eyebrows (01.–06.) on sections.
Flourishes: reveal-on-scroll, scroll-spy nav, animated skill bars, availability
pulse, card hover elevation + arrow nudge — all with reduced-motion fallbacks.

Text on an accent fill uses `text-accent-contrast`, **never white** (white fails
contrast on teal).

Cert provider badges are ORIGINAL in-theme monograms authored from scratch (abstract
marks using accent/surface/border tokens) — never copies of AWS/Cisco trademarked
logos. SVGs are `aria-hidden` with the issuer shown as visible text.

## Hard don'ts

- Do NOT use `next/font/google`.
- Do NOT add `@tailwindcss/turbopack` or any Turbopack CSS rule — use the standard
  `@tailwindcss/postcss` path (`postcss.config.mjs`, `@import "tailwindcss";` +
  `@plugin "@tailwindcss/typography";`).
- Do NOT run `npm audit fix --force`.
- Originality rule: echo design principles only; never clone another site's code,
  tokens, or copy.
